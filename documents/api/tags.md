# タグAPI（tags）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 認証 |
| --- | --- | --- | --- |
| `GET` | `/sites/@site/tags` | サイトのタグ一覧取得 | 不要 |
| `POST` | `/sites/@site/tags` | サイトにタグを追加 | 必須 |
| `GET` | `/tags/@id` | 詳細取得 | 不要 |
| `PUT` | `/tags/@id` | 更新 | 必須 |
| `DELETE` | `/tags/@id` | 削除 | 必須 |

- `@site`はサイトの`key`。存在しないサイトを指定した場合は`404`
- 認証必須のエンドポイントは、共通ルールのとおり`401` / `502`を返すことがある

## レスポンスの項目

| 項目 | 内容 |
| --- | --- |
| `key` | タグのkey |
| `tag` | タグ名 |
| `site_key` | 所属するサイトのkey |
| `created_at` / `updated_at` | 作成日時・更新日時 |

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `tag` | 必須、255文字以内、先頭に`#`を付けない |

- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる

## GET /sites/@site/tags

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: タグの配列（0件でも`200`）
  - `404`: サイトが存在しない

## POST /sites/@site/tags

- ボディ
  - `tag`（必須）: タグ名
- レスポンス
  - `201`: 登録したタグ
  - `400`: 入力チェックエラー
  - `404`: サイトが存在しない
  - `409`: 同じサイトに同名のタグが登録済み

## GET /tags/@id

- レスポンス
  - `200`: タグ
  - `404`: 該当なし

## PUT /tags/@id

- ボディ
  - `tag`（必須）: タグ名
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー
  - `404`: 該当なし
  - `409`: 同じサイトに同名のタグが登録済み

## DELETE /tags/@id

- コンテンツに付けられている場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `404`: 該当なし
  - `409`: コンテンツに付けられている
