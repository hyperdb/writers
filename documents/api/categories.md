# カテゴリーAPI（categories）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 権限 |
| --- | --- | --- | --- |
| `GET` | `/sites/@site/categories` | サイトのカテゴリー一覧取得 | 不要 |
| `POST` | `/sites/@site/categories` | サイトにカテゴリーを追加 | サイトの執筆者 |
| `GET` | `/categories/@id` | 詳細取得 | 不要 |
| `PUT` | `/categories/@id` | 更新 | サイトの執筆者 |
| `DELETE` | `/categories/@id` | 削除 | サイトの執筆者 |

- `@site`はサイトの`key`。存在しないサイトを指定した場合は`404`
- 権限が必要なエンドポイントは、共通ルールのとおり`401` / `403` / `502`を返すことがある（管理者はすべて操作できる）

## レスポンスの項目

| 項目 | 内容 |
| --- | --- |
| `key` | カテゴリーのkey |
| `category` | カテゴリー名 |
| `parent_key` | 親カテゴリーのkey（最上位は`null`） |
| `site_key` | 所属するサイトのkey |
| `created_at` / `updated_at` | 作成日時・更新日時 |

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `category` | 必須、255文字以内 |
| `parent` | 任意。親カテゴリーの`key`（未指定・空文字は最上位） |

- 親カテゴリーは同じサイトに存在するものに限る
- 更新時、自分自身や自分の子孫を親にはできない（階層の循環を防ぐため）
- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる

## GET /sites/@site/categories

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: カテゴリーの配列（0件でも`200`）
  - `404`: サイトが存在しない

## POST /sites/@site/categories

- ボディ
  - `category`（必須）: カテゴリー名
  - `parent`（任意）: 親カテゴリーの`key`
- レスポンス
  - `201`: 登録したカテゴリー
  - `400`: 入力チェックエラー
  - `404`: サイトが存在しない
  - `409`: 同じサイト・同じ親の中に同名のカテゴリーが登録済み

## GET /categories/@id

- レスポンス
  - `200`: カテゴリー
  - `404`: 該当なし

## PUT /categories/@id

- ボディ（`category`と`parent`を指定する。`parent`を省略すると最上位に移動する）
  - `category`（必須）: カテゴリー名
  - `parent`（任意）: 親カテゴリーの`key`
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー
  - `404`: 該当なし
  - `409`: 同じサイト・同じ親の中に同名のカテゴリーが登録済み

## DELETE /categories/@id

- 子カテゴリーがある、またはコンテンツから参照されている場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `404`: 該当なし
  - `409`: 子カテゴリーがある、またはコンテンツから参照されている
