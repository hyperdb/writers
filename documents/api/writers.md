# 執筆者API（writers）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 権限 |
| --- | --- | --- | --- |
| `GET` | `/writers` | 一覧取得 | 不要（任意） |
| `POST` | `/writers` | 追加 | 管理者 |
| `GET` | `/writers/@id` | 詳細取得 | 不要（任意） |
| `PUT` | `/writers/@id` | 更新（ニックネームのみ） | 管理者または本人 |
| `DELETE` | `/writers/@id` | 削除 | 管理者 |

- 権限が必要なエンドポイントは、共通ルールのとおり`401` / `403` / `502`を返すことがある（管理者はすべて操作できる）

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `user_id` | 必須、32文字以内 |
| `nickname` | 必須、32文字以内 |

- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる（共通ルールの「入力チェックエラー」）
- `is_admin`はAPIでは変更できない（ボディで指定しても無視する）

## レスポンスの項目

| 項目 | 内容 |
| --- | --- |
| `key` | 執筆者のkey |
| `user_id` | commonsのユーザーID（管理者のみ） |
| `nickname` | ニックネーム |
| `is_admin` | 管理者フラグ（管理者のみ） |
| `created_at` / `updated_at` | 作成日時・更新日時 |

- `user_id`と`is_admin`は、管理者のトークンを添付したリクエストでのみ返す（それ以外は項目自体を含めない）
  - ログインIDとなる`user_id`を、誰でも一覧から集められないようにするため
- `GET`でトークンを添付した場合は認証を行う（認証に失敗した場合は`401` / `502`）

## GET /writers

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: 執筆者の配列（0件でも`200`）

## POST /writers

- ボディ
  - `user_id`（必須）: `commons.hyperdb.cloud`のユーザーID
  - `nickname`（必須）: ニックネーム
- レスポンス
  - `201`: 登録した執筆者
  - `400`: 入力チェックエラー
  - `409`: `user_id`が登録済み

## GET /writers/@id

- レスポンス
  - `200`: 執筆者
  - `404`: 該当なし

## PUT /writers/@id

- ボディ
  - `nickname`（必須）: ニックネーム
- `user_id`の付け替えは認めない
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー（`nickname`のみチェック）
  - `404`: 該当なし

## DELETE /writers/@id

- コンテンツまたはサイト執筆者（`site_writers`）から参照されている場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `400`: `@id`が未指定
  - `404`: 該当なし
  - `409`: コンテンツまたはサイト執筆者から参照されている
