# 執筆者API（writers）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 認証 |
| --- | --- | --- | --- |
| `GET` | `/writers` | 一覧取得 | 不要 |
| `POST` | `/writers` | 追加 | 必須 |
| `GET` | `/writers/@id` | 詳細取得 | 不要 |
| `PUT` | `/writers/@id` | 更新（ニックネームのみ） | 必須 |
| `DELETE` | `/writers/@id` | 削除 | 必須 |

- 認証必須のエンドポイントは、共通ルールのとおり`401` / `502`を返すことがある

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `user_id` | 必須、32文字以内 |
| `nickname` | 必須、32文字以内 |

- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる（共通ルールの「入力チェックエラー」）

## GET /writers

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: 執筆者の配列（0件でも`200`）。各要素は`id`を除き`key`を付与

## POST /writers

- ボディ
  - `user_id`（必須）: `commons.hyperdb.cloud`のユーザーID
  - `nickname`（必須）: ニックネーム
- レスポンス
  - `201`: 登録した執筆者（`id`を除き`key`を付与）
  - `400`: 入力チェックエラー
  - `409`: `user_id`が登録済み

## GET /writers/@id

- レスポンス
  - `200`: 執筆者（`id`を除き`key`を付与）
  - `404`: 該当なし

## PUT /writers/@id

- ボディ
  - `nickname`（必須）: ニックネーム
- `user_id`の付け替えは認めない
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー（`nickname`のみチェック）
  - `404`: 該当なし

## DELETE /writers/@id

- コンテンツまたはサイト執筆者（`site_writers`）から参照されている場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `400`: `@id`が未指定
  - `404`: 該当なし
  - `409`: コンテンツまたはサイト執筆者から参照されている
