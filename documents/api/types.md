# コンテンツタイプAPI（types）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 権限 |
| --- | --- | --- | --- |
| `GET` | `/types` | 一覧取得 | 不要 |
| `POST` | `/types` | 追加 | 管理者 |
| `GET` | `/types/@id` | 詳細取得 | 不要 |
| `PUT` | `/types/@id` | 更新 | 管理者 |
| `DELETE` | `/types/@id` | 削除 | 管理者 |

- タイプは全サイト共通（サイトに属さない）
- 権限が必要なエンドポイントは、共通ルールのとおり`401` / `403` / `502`を返すことがある（管理者はすべて操作できる）

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `name` | 必須、255文字以内 |

- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる

## GET /types

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: タイプの配列（0件でも`200`）。各要素は`id`を除き`key`を付与

## POST /types

- ボディ
  - `name`（必須）: タイプ名
- レスポンス
  - `201`: 登録したタイプ
  - `400`: 入力チェックエラー
  - `409`: `name`が登録済み

## GET /types/@id

- レスポンス
  - `200`: タイプ
  - `404`: 該当なし

## PUT /types/@id

- ボディ
  - `name`（必須）: タイプ名
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー
  - `404`: 該当なし
  - `409`: `name`が他のタイプで登録済み

## DELETE /types/@id

- コンテンツから参照されている場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `404`: 該当なし
  - `409`: コンテンツから参照されている
