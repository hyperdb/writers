# コンテンツAPI（contents）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 権限 |
| --- | --- | --- | --- |
| `GET` | `/sites/@site/contents` | サイトのコンテンツ一覧取得 | 不要（任意） |
| `GET` | `/sites/@site/contents/@type` | サイトの指定タイプのコンテンツ一覧取得 | 不要（任意） |
| `GET` | `/sites/@site/contents/@type/latest` | サイトの指定タイプの新着一覧取得 | 不要 |
| `POST` | `/sites/@site/contents` | サイトにコンテンツを追加 | サイトの執筆者 |
| `GET` | `/contents/@id` | 詳細取得 | 不要（任意） |
| `PUT` | `/contents/@id` | 更新 | 本人（サイトの執筆者に限る） |
| `DELETE` | `/contents/@id` | 削除 | 本人（サイトの執筆者に限る） |

- `@site`はサイトの`key`。存在しないサイトを指定した場合は`404`
- `@type`はタイプの`key`。存在しないタイプを指定した場合は`404`
- 権限が必要なエンドポイントは、共通ルールのとおり`401` / `403` / `502`を返すことがある（管理者はすべて操作できる）

## 公開状態と取得範囲

- 認証なしの`GET`は、公開中のコンテンツ（`status`が`published`かつ`published_at`が現在日時以前）のみ返す
  - 下書きや公開予約中のコンテンツの詳細は`404`とする
- `GET`でBearerトークンを添付した場合は認証を行う（認証に失敗した場合は`401` / `502`）
  - サイトの執筆者（管理者を含む）は、そのサイトの下書き・公開予約中も含めて返す
  - それ以外のユーザーは、認証なしと同じく公開中のみ返す（`403`にはしない）

## レスポンスの項目

| 項目 | 内容 |
| --- | --- |
| `key` | コンテンツのkey |
| `title` | タイトル |
| `body` | 本文（マークダウン） |
| `status` | 公開状態（`draft`: 下書き、`published`: 公開） |
| `published_at` | 公開日時（未公開の下書きは`null`） |
| `type_key` | タイプのkey（未定は`null`） |
| `category_key` | カテゴリーのkey（未定は`null`） |
| `site_key` | 所属するサイトのkey |
| `writer_key` | 執筆者のkey |
| `tags` | 付けられたタグの配列（各要素は`key`と`tag`） |
| `created_at` / `updated_at` | 作成日時・更新日時 |

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `title` | 必須、255文字以内 |
| `body` | 任意、65,535バイト以内 |
| `status` | 任意（既定値`draft`）、`draft`または`published` |
| `published_at` | 任意、`Y-m-d H:i:s`形式 |
| `type` | 任意、タイプの`key`（未指定・空文字は未定） |
| `category` | 任意、同じサイトのカテゴリーの`key`（未指定・空文字は未定） |
| `tags` | 任意、同じサイトのタグの`key`の配列 |

- `status`が`published`で`published_at`が未指定の場合、公開日時は「既に公開日時があればそのまま、なければ現在日時」とする
- 未来の`published_at`を指定すると公開予約になる（その日時まで認証なしの`GET`には出ない）
- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる
- 執筆者（`writer_key`）はボディでは指定せず、追加時にトークンの持ち主を設定する。更新しても変わらない（管理者が更新した場合も元の執筆者のまま）

## GET /sites/@site/contents

- クエリパラメーター
  - `page`, `rows`（共通ルールのページング）
  - `category`, `tag`, `type`, `writer`: それぞれの`key`で絞り込む（複数指定時はすべてに一致するもの）
- 並び順: 公開日時の新しい順（公開日時のない下書きは最後）
- レスポンス
  - `200`: コンテンツの配列（0件でも`200`。存在しない`key`で絞り込んだ場合も0件）
  - `404`: サイトが存在しない

## GET /sites/@site/contents/@type

- `GET /sites/@site/contents`をパスのタイプで絞り込んだもの。タイプの絞り込み以外（公開状態と取得範囲・クエリパラメーター・並び順）は同じ
  - クエリパラメーターの`type`は無視する（パスのタイプを優先）
- レスポンス
  - `200`: コンテンツの配列（0件でも`200`。存在しない`key`で絞り込んだ場合も0件）
  - `404`: サイトまたはタイプが存在しない

## GET /sites/@site/contents/@type/latest

- フロントエンドの新着記事一覧用。公開中のコンテンツのみ返す
  - トークンは使わない（添付されていても認証せず、下書き・公開予約中は含めない）
- クエリパラメーター
  - `limit`: 取得件数（既定値`10`、上限`10`。0以下・数値でない値は既定値、上限を超える値は上限として扱う）
- 並び順: 公開日時の新しい順（同じ公開日時はIDの大きい順）
- レスポンス
  - `200`: コンテンツの配列（項目は一覧と同じ。0件でも`200`）
  - `404`: サイトまたはタイプが存在しない

## POST /sites/@site/contents

- ボディ: 入力チェックの各項目
- レスポンス
  - `201`: 登録したコンテンツ
  - `400`: 入力チェックエラー
  - `403`: サイトの執筆者ではない
  - `404`: サイトが存在しない

## GET /contents/@id

- レスポンス
  - `200`: コンテンツ
  - `404`: 該当なし（認証なしの場合、公開中でないものも含む）

## PUT /contents/@id

- ボディ: 入力チェックの各項目（すべて指定し直す。省略した任意項目は未定・タグなし・下書きとして扱う）
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー
  - `403`: 本人のコンテンツではない、または本人がサイトの執筆者ではない
  - `404`: 該当なし

## DELETE /contents/@id

- 付けられたタグの紐付け（`content_tags`）も合わせて削除する
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `403`: 本人のコンテンツではない、または本人がサイトの執筆者ではない
  - `404`: 該当なし
