# サイトAPI（sites）

共通ルールは`/documents/api-conventions.md`、項目の意味は`/documents/Entities.md`を参照してください。

## エンドポイント一覧

| メソッド | パス | 内容 | 認証 |
| --- | --- | --- | --- |
| `GET` | `/sites` | 一覧取得 | 不要 |
| `POST` | `/sites` | 追加 | 必須 |
| `GET` | `/sites/@id` | 詳細取得 | 不要 |
| `PUT` | `/sites/@id` | 更新 | 必須 |
| `DELETE` | `/sites/@id` | 削除 | 必須 |

- 認証必須のエンドポイントは、共通ルールのとおり`401` / `502`を返すことがある

## 入力チェック

| 項目 | ルール |
| --- | --- |
| `url` | 必須、`http://`または`https://`で始まるURL形式、255文字以内 |
| `name` | 必須、255文字以内 |

- `url`は末尾の`/`を除去してから検証・保存する（`https://example.com/`と`https://example.com`を同じURLとして扱うため）
- チェックに失敗した場合は`400`を返し、`data`に項目ごとのエラーメッセージを入れる（共通ルールの「入力チェックエラー」）

## GET /sites

- クエリパラメーター: `page`, `rows`（共通ルールのページング）
- レスポンス
  - `200`: サイトの配列（0件でも`200`）。各要素は`id`を除き`key`を付与

## POST /sites

- ボディ
  - `url`（必須）: サイトのURL
  - `name`（必須）: サイト名
- レスポンス
  - `201`: 登録したサイト（`id`を除き`key`を付与）
  - `400`: 入力チェックエラー
  - `409`: `url`が登録済み

## GET /sites/@id

- レスポンス
  - `200`: サイト（`id`を除き`key`を付与）
  - `404`: 該当なし

## PUT /sites/@id

- ボディ（`url`と`name`の両方を指定する）
  - `url`（必須）: サイトのURL
  - `name`（必須）: サイト名
- レスポンス
  - `200`: 更新成功（`data`は空配列）
  - `400`: 入力チェックエラー
  - `404`: 該当なし
  - `409`: `url`が他のサイトで登録済み

## DELETE /sites/@id

- 紐付くデータ（コンテンツ・カテゴリー・タグ・サイト執筆者）が1件でもある場合は削除しない
- レスポンス
  - `200`: 削除成功（`data`は空配列）
  - `404`: 該当なし
  - `409`: 紐付くデータが残っている
